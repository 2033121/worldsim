# WorldSim · 世界模拟 → 网文生产引擎

WorldSim 是一个运行在本机（端口 48091）的多Agent世界模拟器：
模拟出"一个世界真实地运转"，再把编年史自动改写成小说。

## 首次使用检查（新设备/新环境，AI 接到任务先过一遍）

1. **服务是否活着**：调 `world_list`。若报"服务未启动"，**用终端执行**
   `sh /sdcard/Download/Operit/plugins/worldsim/run.sh`（有 super_admin 时用 terminal，
   没有就明确告诉用户手动跑）→ 再 `world_list` 确认。
2. **LLM 是否配置**：`world_list` 能通但 `world_readiness` 返回空/报错，或跑模拟全 dry-run →
   提示用户打开 WebUI `http://127.0.0.1:48091` 操作台填 LLM（Base URL/模型/Key）→ 点"应用"。
3. **确认主题包**：`world_themes` 应返回 15 个主题包（缺失说明 worldbooks/themes 没装全）。
4. **开始创作**：按下方标准工作流。

## 架构速览

- **世界模拟器**：事件驱动。每天生成事件（冲突/奇遇/生活切片…）→ 主角三问决策 → NPC 互动 → 世界状态演化 → 记忆沉淀 → 伏笔埋设/回收。时间跳跃按世界尺度自适应（修仙跳年/末世跳日）。
- **世界书体系**：`_template.md` 通用骨架 + `themes/` 15个主题包（经典修仙/都市异能/末世废土/西幻奇幻/恐怖灵异/历史王朝/星际科幻/无限诸天/武侠玄幻/美食种田/原始文明/军旅战争/洪荒神话/克苏鲁异界/系统流）。选主题包 + 一句话设定 → LLM 自动生成完整世界书。
- **就绪度驱动**：模拟不按天数结束，按"素材够不够写小说"（完成段落≥3 + 戏剧素材≥12 + 伏笔回收≥1 + 张力≥0.4）自动判定，就绪后可生成小说。
- **岔口决策队列**：剧情遇到多方向岔口时 AI 自动代决（不阻塞），用户可随时翻案改选，写手按用户方向写。
- **双控制入口**：
  - AI 控制：`worldsim` 沙盒包（use_package 激活，22个工具）
  - 用户控制：WebUI 可视化控制台 `http://127.0.0.1:48091`（世界状态/决策改选/循环开关/就绪度/小说阅读）

## 标准工作流（AI 代用户操作时按此顺序）

1. **确认服务活着**：`world_list` 报"服务未启动"时，先让用户运行插件包内的 `run.sh`（或直接帮用户运行），再继续。
2. **选世界**：已有世界用 `world_select` 切换；开新世界用 `world_create`（**强烈建议传 theme 主题包 + desc 一句话设定**，LLM 自动生成贴合题材的世界书）。
3. **初始化**：`world_init` 按世界书生成主角/NPC/地点（主角名可不传，LLM 自拟）。
4. **跑模拟**：
   - 手动小步：`world_run_day`（1-30天，mode=auto）
   - 长时间积累：`world_loop_start`（后台持续跑，到就绪自动停）→ `world_loop_status` 查进度
5. **查就绪**：`world_readiness`。就绪前可看 `world_state`/`world_chronicle`/`world_decisions` 跟进剧情；**有决策队列时主动告知用户可翻案**（`world_decision_resolve`）。
6. **写小说**：就绪后 `world_novel_generate`（1-3分钟/章）→ `world_novel_list` → `world_novel_chapter` 读正文。
7. **用户要自己看**：`world_webui` 给出控制台地址，引导用户打开浏览器操作（翻案/看小说/开关循环）。

## 关键规则

- **题材自适应**：任何世界都用同一套引擎。世界书决定质感——修仙世界生成测灵根/丹炉/宗门杂役，末世生成搜寻/尸潮/营地，不要拿都市模板套别的世界。
- **决策翻案优先**：用户明确说"不选A，选B"时，立即 `world_decision_resolve`，且后续生成内容按用户方向推进。
- **不要替用户做重大剧情决定**：AI 代决是兜底（用户没时间时），一旦用户在场表达倾向，以用户为准。
- **就绪度不是天数**：别等"跑满N天"，看 `world_readiness` 的 ready。
- **LLM 超时容忍**：中转站不稳定时单日失败是常态，`world_loop_start` 会自愈重试，别频繁手动重跑。
- **素材库**：写手有 886+ 条真实网文示范素材（跨题材），写出来的章节要有人味，别 AI 腔。

## 故障排查

| 现象 | 处理 |
|---|---|
| 所有工具报"服务未启动" | worldsim 进程没跑：运行插件包 `run.sh` |
| 创建世界报"主题包不存在" | 先 `world_themes` 看可用主题包名 |
| 模拟超时/事件空 | LLM 中转站抖动，重试或开 `world_loop_start` 自愈 |
| 小说生成为空 | 先 `world_readiness` 确认就绪；素材不够就继续跑 |
| 决策队列很长 | 正常（AI 代决不阻塞），用户可在 WebUI 或 `world_decision_resolve` 翻案重要的 |
