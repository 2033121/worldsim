# 美术工坊 — 世界书驱动的像素素材生成（v1.8.0）

每个世界可以有自己的一套像素美术：人物、怪物、场景、地图块、物品。你不写提示词也能出图——AI 先读你的世界书做「素材规划」，你在 UI 里微调后一键生成，产物直接接入游玩页。

## 快速开始

1. **配置图片服务**：打开 `http://127.0.0.1:48092/studio`（或统一外壳「美术工坊」Tab）
   - Base URL：OpenAI images 协议的中转站（如 `http://ai.jiuqingyunapi.top`），模型默认 `gpt-image-2`
   - API Key：填入或留空（则用环境变量 `GPTIMG_KEY`）
   - 点「测试连通」出一张 64x64 小图即通
2. **生成规划**：选好世界 → 点「从世界书生成规划」（LLM 一次调用，约 1~3 分钟）
3. **（可选）编辑规划**：规划表里逐条改名称/中文速写/英文提示词 → 「保存规划修改」
4. **生成图片**：「全部生成」（5 张 sheet ≈ 5 次请求）或按类单点；约 40~60 秒/张
5. **游玩验证**：打开 `/game`（或统一外壳「文字游戏」页）——主角立绘已是本世界素材，检定失败切怪物像

## 产出什么

每世界目录下 `art/`：

```
art/
├── plan.json      # 素材规划（12人物/8怪物/3场景/16地图块/24物品，每条：名称+角色+中文速写+英文prompt）
├── sheets/        # 5 张原始 sheet（characters/monsters/scenes/maptiles/items.png）
├── sprites/       # 63 个透明底 sprite（character-1..12 / monster-1..8 / scene-1..3 / tile-1..16 / item-1..24）
├── history.json   # 每次生成的留痕（时间/类型/条目/prompt/尺寸）——可追溯、可重掷
└── jobs.json      # 任务历史
```

## 规划的提示词工程（怎么保证出图质量）

- **代码层注入（不靠 LLM 记住）**：16-bit 像素风、厚描边、统一 `#e8e8e8` 纯灰底、禁文字/数字/水印/网格线；人物=正面全身站姿统一脚线、怪物=威胁姿态、tile=俯视可平铺、物品=干净图标 1px 描边
- **世界专属调色板**：规划 Agent 从题材推导 `palette`（文字描述）+ `palette_hex`（6~10 个色值），注入每条 prompt——同一世界多张图风格一致的关键
- **覆盖红线**：人物含主角/同伴/导师/对手/路人梯度；怪物按本世界威胁谱自拟；tile 覆盖安全地/道路/水/林/遗迹/传送点等功能谱
- **世界书「美术设定」段最高优先**：模板新增可选段（视觉基调/主角外观/调色板/标志性场景），写了就遵循；留空则 AI 从 A1~A4 自拟

## 服务器细节（自部署/二创参考）

- 生成器**可插拔**：`img.json` 的 `provider` = `openai_images`（默认）| `pixellab`（PixelLab Pixflux，`no_background` 直出透明底）
- 单品再生成：改某条规划后点「重生成」——只出一张 1024x1024，裁剪后覆盖该 sprite，不动其它资产
- 空格自动补齐：裁剪后检出空格/废格，自动走单品流程重生成（最多 2 轮），仍失败标告警不阻塞
- HTTP API：`GET/POST /api/art/config`（key 永远掩码）· `POST /api/art/config/test` · `POST/GET/PUT /api/art/plan` · `POST /api/art/generate`（`{assets:[...]}` 批量 / `{label,index}` 单品，异步）· `GET /api/art/jobs[/{id}]` · `GET /api/art/assets` · `GET /api/art/history` · `GET /art/{file}.png`
- 密钥安全：`img.json` 在程序数据目录（不进仓库）、`api_key` 只写不读、API 回显一律掩码
- 像素套件主题（打包兜底）：`docs/art/pixel/<theme>/`，无本世界规划时由 `detectPixelTheme` 题材推断回落

## 与打包套件的关系

| | 打包套件（v1.7.0） | 美术工坊（v1.8.0） |
|---|---|---|
| 素材来源 | 仓库预置 5 主题 × 63 资产 | AI 按你的世界书现做 |
| 落盘 | `docs/art/pixel/` | `<world>/art/` |
| 服务路由 | `/pixel-art/{theme}/{file}.png` | `/art/{file}.png` |
| 优先级 | 兜底 | **优先**（有 `plan.json` 即用） |
