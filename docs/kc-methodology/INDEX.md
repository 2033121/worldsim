## 二、核心工作流类（5张）详解

> 核心工作流是写作的「地图」——告诉你从哪里来、到哪里去、中间经过哪些站。
>
> 它们不教你具体怎么写，而是教你**先做什么、后做什么、每个阶段要交付什么**。

### KC-FLOW-001 创作全流程工作流

**一句话定位：** 从0到1再到0的完整创作周期全景图。新手入门第一张卡。

**核心价值：**
- 建立全局视角，知道每一步在整个体系中的位置
- 避免走一步看一步、写到哪算哪的盲目写作
- 每个阶段有明确的交付物和准入准出标准

**七阶段概览：**
立项与定位 → 世界观构建 → 人物塑造 → 大纲设计 → 开篇写作 → 连载运营 → 完本复盘

**调用建议：** 新手作者先吃透这张卡，建立全局认知后再深入细节。

### KC-FLOW-002 立项与题材选择工作流

**一句话定位：** 找对赛道比努力更重要，立项阶段决定了一本书的天花板。

**核心价值：**
- 用系统化方法替代"凭感觉选题"
- 从市场、受众、自身能力三维评估可行性
- 提炼差异化卖点，避免同质化竞争

**五阶段概览：**
市场调研 → 自我评估 → 受众画像 → 卖点提炼 → 可行性验证

**调用建议：** 开新书前必走流程，宁可多花3天调研，不要写30万字才发现走错赛道。

### KC-FLOW-003 大纲与结构设计工作流

**一句话定位：** 骨架决定能走多远，大纲崩了后面写得再好也是白搭。

**核心价值：**
- 从一句话梗概到百万字大纲的完整路径
- 确保故事有核心冲突、有起承转合、有高潮收尾
- 预防中期崩盘、节奏失控、主线跑偏

**六阶段概览：**
核心冲突设计 → 主线搭建 → 分卷规划 → 人物弧光 → 伏笔系统 → 节奏编排

**调用建议：** 长篇作品（20万字以上）必须做，短篇可适当简化但不能没有。

**五阶段概览：**
主角设计 → 配角配置 → 反派塑造 → 关系网络 → 成长弧光

### KC-FLOW-005 世界观设定工作流

**一句话定位：** 世界自洽，读者才信；世界观是故事的舞台，舞台稳了戏才好唱。

**核心价值：**
- 从表层到深层的五层世界观构建法
- 战力/能力体系的防崩设计
- 设定为剧情服务，不为设定而设定

**五阶段概览：**
核心规则设计 → 势力格局设计 → 文化心理塑造 → 地理历史铺陈 → 自洽性验证

**调用建议：** 玄幻/科幻/奇幻等强设定题材必做，现实题材可简化为背景设定。

## 三、执行SOP类（5张）详解

> SOP是写作的「操作手册」——不仅告诉你要做什么，还手把手教你**第一步做什么、第二步做什么、每一步怎么检验**。
>
> 核心工作流是"道"，执行SOP是"术"；道指引方向，术落地执行。

### KC-FLOW-006 开篇写作SOP

**一句话定位：** 把零散的开篇技能组装成可直接执行的标准作业流程，确保每一篇开篇都能达到签约及格线。

**六阶段概览：**
1. 立项与题材选择 → 找对赛道，提炼卖点

4. 大纲与开篇结构 → 搭建骨架，规划三章
5. 正文写作与润色 → 写出正文，打磨语言
6. 自检与修改 → 对照标准，反复打磨

**预计耗时：** 2-3天
**适用场景：** 新书开篇、投稿前准备、开篇重写

### KC-FLOW-007 章节写作SOP

**一句话定位：** 日常更新的标准化作业流程，让每天打开文档就能写，写完就能发，稳定产出不卡文。

**五阶段概览：**
1. 章前准备 → 回顾前文、明确目标、定位类型
2. 章节细纲 → 搭骨架、分配字数、标爽点钩子
3. 初稿写作 → 快速产出、先完成再完美
4. 润色修改 → 补细节、调节奏、去AI味
5. 终检发布 → 错别字、首尾、伏笔检查

**预计耗时：** 2-4小时/章（2000-3000字）
**适用场景：** 日常更新、批量存稿、赶稿应急

---

### KC-FLOW-008 修改润色SOP

**一句话定位：** 七轮修改法，从宏观到微观逐层打磨，好文章是改出来的。

**七轮修改法：**
1. 第一轮：结构审查 → 大纲层面，有没有跑偏、有没有崩
2. 第二轮：人设校准 → 人物有没有OOC、行为逻辑对不对
3. 第三轮：节奏调整 → 快慢松紧、爽点密度、情绪起伏
4. 第四轮：情感深化 → 情感真不真、戳不戳、够不够浓
5. 第五轮：语言打磨 → 遣词造句、画面感、去AI味
6. 第六轮：逻辑闭环 → 前后矛盾、伏笔回收、因果自洽
7. 第七轮：终检校对 → 错别字、语病、格式、细节

**适用场景：** 开篇精修、完本打磨、关键章节修改、签约前润色

---

### KC-FLOW-009 数据诊断与调整SOP

**一句话定位：** 用数据驱动内容优化，不是凭感觉瞎改，而是系统化诊断、精准化调整。

**五阶段诊断流程：**
1. 数据采集与指标识别 → 拉数据、懂指标、明基准
2. 异常定位与问题初判 → 找异常、定范围、排优先级
3. 根因分析与内容诊断 → 挖根源、交叉验证、找真因
4. 方案制定与执行落地 → 定方案、改内容、控变量
5. 效果追踪与迭代优化 → 看数据、验效果、调策略

**预计耗时：** 每周30分钟（常规诊断）
**适用场景：** 每周数据复盘、数据异常应急、推荐期优化

### KC-FLOW-010 世界观构建SOP

**一句话定位：** 从一个念头到一个自洽、有深度、有生命力的世界观，七步标准化流程。

1. 核心矛盾定义 → 找到世界观的"魂"

## 五、SOP使用说明

### SOP是什么？

**SOP = Standard Operating Procedure = 标准作业流程**

简单说，SOP就是把"怎么干这件事"拆解成一步一步的标准化动作，让任何人照着做都能达到及格线以上的水平。

- **核心工作流**回答的是"做什么"（What）——每个阶段有哪些任务、交付什么
- **执行SOP**回答的是"怎么做"（How）——每个任务具体怎么操作、步骤是什么
- **技能卡**回答的是"用什么做"（With What）——每个步骤调用哪些技能和方法

**三者关系：**
```
核心工作流（地图） → 执行SOP（路线） → 技能卡（交通工具）
```

---

### 什么时候用SOP？

| 场景 | 推荐SOP | 为什么用 |
|:-----|:--------|:---------|
| **开新书写开篇** | 006 开篇写作SOP | 避免东一榔头西一棒子，按流程走效率最高 |
| **日常更新卡文** | 007 章节写作SOP | 流程化作业，减少决策成本，打开文档就能写 |
| **感觉写得不好** | 008 修改润色SOP | 七轮修改法，从大到小逐层打磨，不会漏项 |
| **数据掉得厉害** | 009 数据诊断SOP | 系统化诊断，找到真因，不要凭感觉瞎改 |
| **搭世界观** | 010 世界观构建SOP | 七步标准化流程，从零到自洽 |
| **投稿前准备** | 006 + 008 | 先用开篇SOP写，再用修改SOP磨，双保险 |
| **每周复盘** | 009 数据诊断SOP | 固定动作，形成习惯，数据驱动持续进步 |

---

### 怎么用SOP？

#### 三步使用法

**第一步：通读全流程，建立全局认知**
- 先把SOP从头到尾读一遍，知道分几个阶段、每个阶段做什么
- 不要上来就扎进细节，先看森林再看树木

**第二步：按步骤执行，不要跳步**
- 严格按照SOP的顺序来，一步一步做
- 为什么不能跳步？因为SOP的顺序是无数人踩坑踩出来的最优解
- 跳步看起来快，实际上后面会花更多时间补坑

**第三步：用检查清单验收，确保质量**
- 每个阶段完成后，对照检查清单打勾
- 没通过就不要进入下一个阶段
- 自检越严格，后面返工越少

#### 进阶使用技巧

1. **先僵化，后优化，再固化**
   - 刚开始用的时候，严格照着做，不要自己瞎改
   - 用熟了之后，根据自己的习惯和风格调整
   - 最终形成自己的SOP，那才是真正属于你的东西

2. **搭配技能卡使用，效果倍增**
   - SOP是流程骨架，技能卡是血肉填充
   - SOP告诉你"这一步要做什么"，技能卡告诉你"怎么做得更好"
   - 每张SOP卡中都标注了对应阶段调用的技能卡，直接用就行

3. **定期复盘迭代**
   - 每用一次SOP，记下来哪里卡壳了、哪里可以优化
   - 每月回头看看，你的SOP是不是越来越顺手
   - SOP不是死的，是活的，要跟着你一起成长
